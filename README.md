#dna analysis tool
This repository contains to basic dna analysis tools
**dna base counter** it counts A,T,G,C in a dna sequence
**GC content calculator** It counts percentage of gc content in a dna sequence
Significance:
dna base counter can help in diagnosis of diseases that involve mutations in number of nucleotide bases by comparing it's number with that of normal number of bases
gc calculator can guide in setting up temperature in PCR tests as a hight percentage od gc would require high temperature to break the bonds
